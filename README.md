# StreamLark TV

> **Android 5.0+ 的遥控器优先视频客户端。**

StreamLark TV 是一个面向 Android TV 与大屏设备的开源视频客户端工程，目标是在 **Android 5.0（API 21）及以上版本**提供稳定、轻量且以遥控器焦点操作为核心的视频浏览与播放体验。项目将以独立实现的方式构建推荐流、搜索、收藏、播放历史、预加载、画中画和直播弹幕等通用能力，而不会复制任何第三方应用的私有源码、品牌资产或受保护内容。

## 项目定位

本项目服务于仍在运行 Android 5.0–Android 7.x 的电视盒子、老电视和大屏终端。相较于依赖较新系统版本的现代 Android 客户端，StreamLark TV 将以 **API 21 为最低兼容版本**，优先采用成熟的 Android View、RecyclerView、Media3/ExoPlayer 与 Kotlin 协程组件，并将新平台能力封装为可选增强，而非运行前提。

| 维度 | 设计原则 |
|---|---|
| 兼容性 | `minSdk 21`，核心播放与遥控交互可运行在 Android 5.0。 |
| 交互 | 以十字键、确认键、返回键和焦点可见性为第一优先级。 |
| 播放 | 支持 HLS/HTTP(S) 媒体地址、清晰度选择、进度记忆、预加载与画中画降级策略。 |
| 数据 | 采用可插拔 Content Provider 接口；默认提供演示/本地数据源。 |
| 隐私 | 不收集用户 Cookie，不内置第三方账户抓取或绕过逻辑；凭证接入仅面向用户已获授权的 Provider。 |
| 安全 | 默认禁用明文网络流量；敏感令牌由 Android Keystore 加密保护；日志不得输出授权头或会话凭证。 |

## 规划功能

第一阶段将提供 TV 首页、分类内容流、遥控器焦点导航、搜索、详情页、收藏、历史记录和沉浸式播放器。播放器支持连续播放、上下条切换、可控的下一条预加载、进度条、清晰度选择及 Android 8.0+ 的画中画增强；在 Android 5.0–7.x 上将自动回退为等价的全屏播放体验。

第二阶段将提供直播房间、弹幕渲染、内容合集、用户主页和二维码配对等能力。所有外部内容接入必须通过独立 Provider 实现并遵守来源平台规则。演示数据、用户自有媒体或正式授权的服务端 API 将作为默认开发与测试路径。

## 计划中的工程结构

```text
streamlark-tv/
├── app/                    # Android 入口、TV 页面与播放器宿主
├── core/
│   ├── model/              # 视频、直播、搜索与用户领域模型
│   ├── player/             # Media3/ExoPlayer 播放与预加载策略
│   ├── data/               # 本地数据库、历史、收藏和 Provider 接口
│   └── security/           # Keystore、日志脱敏与网络安全策略
├── provider-demo/          # 演示内容与本地媒体 Provider
├── docs/                   # 架构、兼容性及贡献文档
└── scripts/                # 构建、验证与发布辅助脚本
```
